# 💣 扫雷 Minesweeper

经典Windows扫雷游戏的网页版实现，使用HTML+CSS+JS原生技术，无第三方依赖。

## 功能特性

- 🎮 **经典玩法**：与Windows扫雷完全一致的规则和交互
- 🎯 **三种难度**：初级(9×9, 10雷)、中级(16×16, 40雷)、高级(30×16, 99雷)
- 🚩 **右键标旗**、双击快速揭开(Chord)、自动展开空白区域
- 💥 **踩雷爆炸特效**、😎胜利、😵失败表情反馈
- 📱 **响应式设计**：格子大小自适应屏幕宽度，支持移动端
- ⌨️ **键盘快捷键**：1/2/3切换难度，R重新开始
- ⏱️ **计时器**与**雷计数器**

## 运行方式

双击 `index.html` 即可在浏览器中运行，无需任何服务器或构建步骤。

## 项目结构

```
扫雷/
├── index.html         # 游戏入口页
├── style/
│   └── style.css      # 经典扫雷样式（3D边框效果）
├── js/
│   └── main.js        # 游戏核心逻辑
├── images/            # 图片资源目录
├── AGENTS.md          # AI开发规范文档
└── README.md          # 本文件
```

## 操作说明

| 操作 | 方式 |
|------|------|
| 揭开格子 | 左键点击 |
| 标记/取消旗帜 | 右键点击 |
| 快速揭开 | 双击已揭开的数字格 |
| 重新开始 | 点击😊笑脸按钮 / 按R键 |
| 切换难度 | 点击难度按钮 / 按1/2/3键 |
